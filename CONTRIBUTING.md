# Contributing

Thanks for helping keep this list awesome! A few rules:

1. **Free tier is mandatory.** Only suggest tools with a genuinely usable free tier — no credit card required to sign up and use it.
2. **One line per tool.** Format: `- [Name](https://link) — What it does + what the free tier gives.`
3. **Alphabetical order** within each category.
4. **No duplicates.** Check the list first.
5. **No affiliate or referral links.** Clean official links only.

Open a pull request with your addition. That's it!
